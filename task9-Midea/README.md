# task9-美的集团 双均线策略回测

## 标的
- 美的集团 (000333.SZ) — 深圳主板白电龙头
- 数据范围: 2025-07-01 ~ 2026-07-10 (250 交易日)
- 数据源: 腾讯行情 (qfq 前复权)

## 策略
- MA5/MA15 双均线交叉
- 金叉买入(当日open价)、死叉卖出(当日open价)
- 信号: signal=1/-1(状态) → position=signal.diff()(±2交叉) → exec_signal=signal.shift(1)(避免未来函数)

## 交易成本
- 佣金万2.5双边 + 印花税卖出千1 + 滑点单边千2
- 买入总成本率: 0.225%
- 卖出总成本率: 0.325%

## 分析
美的集团这一年涨了16.34%，是温和趋势市。双均线策略表现：
1. **回撤控制优于基准**：策略MDD -10.79% < 基准 -12.90%，双均线在温和市中能有效规避部分回调
2. 但收益大幅落后：+4.43% vs +16.07%，频繁切换(1.3信号/月)产生踏空
3. 胜率仅42.9%，低于50%，说明多数交易是亏损的
4. 夏普比率0.170远低于基准0.728，风险调整后收益不佳

**对比task8兆易创新**：兆易创新极端牛市(+397%)策略跑输基准192个百分点；美的温和市(+16%)策略跑输基准12个百分点。双均线在温和市中差距更小，且回撤控制有优势。
