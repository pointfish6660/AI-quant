⚠ 注意事项 & 使用建议

1. TA-Lib 未安装：Python 3.13 无官方预编译 wheel，Windows 下编译 C 扩展繁琐。已用 pandas-ta + ta 替代，覆盖 200+ 技术指标（MACD、RSI、布林带、一目均衡、ATR 等），完全满足需求。

2. empyrical / pyfolio 弃用：Quantopian 已停维，Python 3.13 不兼容（configparser.SafeConfigParser 在 3.12+ 已移除）。改用 quantstats 替代，可直接生成 HTML 绩效分析报告。

3. numba 版本冲突：vectorbt 需要 numba ≥ 0.66，pandas-ta 声明 numba == 0.61.2。实测 pandas_ta 在 numba 0.66 下可正常 import 和运行，若遇异常可优先保留 vectorbt，用 ta 替代 pandas-ta。

4. 预发布版警告：mplfinance / pandas-ta / jupyterlab / bokeh / lxml 因仅提供 alpha/beta 版而使用了 --pre 安装。功能已验证可用，若出问题可通过 pip install <包名>==<正式版> 降级。

5. numpy 版本路径：因 numba 依赖链，numpy 最终锁定在 2.4.6。如后续安装其他深度学习框架（PyTorch/TensorFlow），注意可能要求不同 numpy 版本，届时用 pip install numpy==<目标版> 调整。

6. 深度学习框架：PyTorch / TensorFlow / Keras 未包含在内（体积大 ≥ 2GB）。如需安装：

# CPU 版 PyTorch（推荐，兼容性好）
pip install torch --index-url https://download.pytorch.org/whl/cpu

# GPU 版需匹配 CUDA 版本，参考 pytorch.org

7. 环境复现：在新机器上可直接用项目根目录的 requirements.txt 复现：

python -m venv env
env\Scripts\activate        # Windows
pip install -r requirements.txt --pre -i https://pypi.tuna.tsinghua.edu.cn/simple

8. Jupyter Lab 启动：双击项目根目录 start_jupyter.bat 或命令行执行 jupyter-lab --notebook-dir="D:\06-weiyuan\BA-quant"，新建 Notebook 时选择 ba-quant kernel。

9. 环境验证：运行 python verify_env.py 可快速检查所有包是否可用，输出分类通过/失败报告。
